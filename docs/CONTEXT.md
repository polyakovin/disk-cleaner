# Контекст проекта DiskLens

Перенесён 9 октября 2026 года из чата [«Найти, куда ушло место на диске»](codex://threads/01a1202c-cf8d-70f3-896d-a4474a34025f). Это сводка решений и результатов, а не полная стенограмма. Исходный чат остаётся источником подробностей.

## Как возник проект

Сначала пользователь запросил диагностику заполненного диска своего Mac. После отчёта попросил оформить такой способ диагностики в скилл для ИИ-агента. Затем запросил легковесное приложение для macOS с аналогичным поиском, переходом к найденным файлам и папкам и подключением ИИ для анализа отчёта и рекомендаций по очистке.

Диагностика 9 октября показала около 484 ГБ занятого места при ёмкости 494 ГБ и примерно 10,5 ГБ свободного места. Основные категории: данные приложений 98 ГБ, установленные приложения 54 ГБ, репозитории 49 ГБ, документы 47 ГБ, офлайн-музыка 46 ГБ, данные Codex 33 ГБ, кэш npm 23 ГБ, CapCut 14 ГБ. Вложенные категории учитывались отдельно только как пояснения. Измеренные кандидаты на очистку занимали около 52 ГБ; это оценка, а не гарантия освобождения такого объёма. Часть системных каталогов была недоступна. Файлы не удалялись. Эти цифры исторические, для актуального отчёта нужен новый замер.

## Что создано

- **DiskLens:** нативное приложение для macOS 14+, Swift Package Manager, SwiftUI, без сторонних пакетов. Исходники находятся в `DiskLens/`.
- **CLI:** `disklens-cli`, использующий тот же сканер.
- **Скилл `disk-space-report`:** инструкции и Python-скрипт измерения. Переносимая копия находится в `skills/disk-space-report/`. В исходном чате скилл также установлен в личный каталог Codex; установка не зависит от этого репозитория.
- **Готовые сборки:** `build/DiskLens.app`, `build/DiskLens-macOS.zip`, исходный архив `build/DiskLens-source.zip` и `build/disk-space-report.zip`. Они сохранены локально и исключены из Git.

Личные отчёты со списками путей, содержимое переписки и временные кэши компилятора в репозиторий не переносились.

Старые пути артефактов в папке исходного чата заменены символическими ссылками на этот проект, поэтому прежние ссылки продолжают работать. Оригиналы до переноса сохранены локально в `build/import-originals/`; история отдельного репозитория DiskLens сохранена также в `build/DiskLens-history.bundle` (исходный коммит `9647514`). Рабочие исходники входят в основной репозиторий, вложенного Git-репозитория в `DiskLens/` нет.

## Принятые технические решения

- Сканер читает метаданные, включая выделенные блоки, скрытые файлы и каталоги. Не читает содержимое файлов, не следует по символическим ссылкам, остаётся на исходной файловой системе, учитывает hard links один раз.
- Сканирование идёт в фоне; недоступные каталоги и отмена дают явно неполный отчёт. Сохраняются крупнейшие ветви первых трёх уровней и до 100 крупнейших файлов, а не всё дерево диска.
- Интерфейс содержит обзор, крупные файлы, кандидатов на очистку и ИИ-помощник. Есть переход в Finder, отдельное сканирование выбранной ветви, экспорт JSON и текста.
- Размеры отображаются в десятичных ГБ. APFS-клоны, снимки и сжатие не позволяют обещать освобождение всего показанного размера.
- ИИ подключается через Codex CLI, локальную команду либо API Responses/Chat Completions. Передача отчёта начинается по действию пользователя. Домашний префикс можно заменить на `~`; названия остальных путей сохраняются.
- Пресет Codex работает в режиме `read-only`, с временной сессией и отключёнными пользовательскими настройками/hooks. Локальная команда запускается без shell. API-ключ хранится в Keychain отдельно для адреса сервера.
- Рекомендации выводятся текстом. Исполнителя очистки, фонового сервиса, автозапуска и телеметрии нет.

## Проверки в исходном чате

По завершённому исходному чату:

- Все 10 тестов прошли. Проверены сканер, отмена, ограничения доступа, ограниченное дерево, экспорт, кандидаты и транспорт ИИ с тестовыми ответами.
- Собрана универсальная версия для Apple Silicon и Intel; подпись локальная ad-hoc.
- На Apple Silicon приложение запускалось, сканирование и настройки ИИ проверены в интерфейсе.
- Переход в Finder проверен: приложение открыло каталог и выделило найденную папку.
- Запросы к живым ИИ-провайдерам не выполнялись. Запуск на Intel, Developer ID и notarization не подтверждены.

Повторные проверки переноса фиксируются отдельно ниже, чтобы не смешивать результаты двух чатов.

## Проверки после переноса 9 октября 2026 года

- Содержимое исходников, скилла, приложения и архивов сверено по SHA-256; сохранены права файлов. Перед заменой старых путей сверка повторена, исходный Git-репозиторий был чистым.
- `python3 scripts/commercial-project.py check .` прошёл; все коммерческие ворота остались `pending`.
- `swift test --package-path DiskLens --disable-sandbox` прошёл: 10 тестов, 0 ошибок.
- `swift build --package-path DiskLens --disable-sandbox -c release` прошёл на Apple Silicon. Песочница среды не разрешает пользовательские кэши SwiftPM; предупреждения о них не остановили сборку.
- У готового приложения проверены универсальный бинарник (`arm64`, `x86_64`), `Info.plist` и ad-hoc подпись. Перенесённая сборка запущена по новому пути, окно DiskLens с обзором и настройкой ИИ подтверждено через интерфейс macOS.
- Повторное сканирование всего диска, запуск на Intel, живая интеграция с ИИ и notarization не выполнялись. Возможности сканирования и Finder подтверждены только указанной выше проверкой исходного чата.
- В основном репозитории на момент переноса нет Git remote; отправка изменений на сервер не настроена.

## Коммерческое состояние и продолжение

В текущем репозитории `commercial-project.json` остаётся источником истины. Стадия `idea`, все ворота `pending`, коммерческие метрики нулевые. Личный запрос и работающее приложение не являются доказательством спроса, интервью, оплаты или выручки.

Текущая задача состоит в переносе уже созданного приложения и контекста. Она не открывает ворота для полной продуктовой разработки. До следующей разработки нужно следовать коммерческому соглашению проекта; технический прототип до `money: go` требует отдельного решения с бюджетом. Обязательных незавершённых доработок в исходном чате не заявлено.
