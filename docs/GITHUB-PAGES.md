# Лендинг DiskLens

Адрес: <https://polyakovin.github.io/disk-cleaner/>.

`site/` содержит статический сайт без сборщика, JavaScript, внешних шрифтов и аналитики. Workflow `.github/workflows/pages.yml` публикует только этот каталог при изменениях сайта в `main`; доступен и ручной запуск. В настройках репозитория источником GitHub Pages должен быть GitHub Actions (`build_type: workflow`).

Локальный просмотр:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory site
```

Лендинг описывает опубликованную версию `v0.1.0`, а не незакоммиченные доработки приложения. Макет отчёта содержит иллюстративные данные, не снимок пользовательского диска. Иконка повторяет исходную иконку DiskLens из `DiskLens/scripts/make-icon.swift`.

При следующем релизе обновить в `site/index.html` номер версии, прямые ссылки на ZIP и SHA-256, размер архива, возможности и ограничения проверки. Ссылки закреплены за конкретным релизом: endpoint `releases/latest/download` пропускает предварительные выпуски.

Проверить относительные ресурсы под `/disk-cleaner/`, якоря, скачивание из GitHub Releases, мобильную вёрстку и переходы с клавиатуры. Выполнить канонические проверки из корневого `AGENTS.md`. После публикации проверить успешный workflow и HTTP 200 для страницы и ресурсов.

При изменении `site/styles.css` обновить параметр `v` у ссылки на него в `site/index.html` первыми 12 символами SHA-256 файла. Это обновляет стили и у посетителей с закэшированной версией.
