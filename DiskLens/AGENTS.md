# Disk Manage

- Native macOS 14+ application. Swift Package Manager, Swift 5.9+; no external dependencies.
- All user-facing UI, errors, exported reports and AI instructions/recommendations use English, including on a non-English macOS system.
- `DiskLensCore` contains the POSIX metadata scanner, report generation and agent transports. It must not import SwiftUI or AppKit.
- `DiskLens` contains UI, Finder integration and Keychain storage. `disklens-cli` exposes the scanner for terminal use and verification.
- Scanner never reads file contents or follows symlinks; stays on the starting filesystem, counts hard links once, marks inaccessible and interrupted scans as partial. Store the complete metadata tree in private SQLite; keep reports and UI pages bounded in memory. Never export the full index to agents.
- Reuse measurements only with continuous device-relative FSEvents history; folder dates alone are insufficient. Invalidate the cursor before mutating the tree and publish the pre-walk cursor only after completion. Keep known measurements on cancellation; revoke obsolete writers. Missing/unstable history and hard-link events require full verification without clearing known data. Retain an explicit full-scan command. The journal is advisory during concurrent writes.
- Scanning runs off the main thread. Keep the live table interactive and refresh an opened folder from current snapshots. Cancellation must retain a visibly partial report immediately; obsolete workers must never restore UI state or scan history, even if a POSIX call returns late.
- Agent integration submits report metadata only on an explicit user action. Recommendations never execute cleanup. Candidate review resolves opaque IDs against a frozen scan; only the user applies proposed changes. UI file actions remove explicitly confirmed objects off the main thread: one item or a non-overlapping candidate batch showing every path, with Trash or a separately selected permanent mode. Never fall back from Trash to permanent deletion. Revalidate all batch identities before starting and each item before removal, stop on the first error, protect roots/system trees, mark changed paths dirty and refresh after success or a potentially partial failure, retaining known measurements. Never store API keys in UserDefaults, exports or Git. Codex preset uses read-only mode and disables user hooks via `--ignore-user-config`.
- Canonical verification: `swift test`, then `swift build -c release`. `scripts/build-app.sh` builds and ad-hoc signs a universal `.app`; test the packaged application before delivering.
- `README.md` describes setup, provider connection and measurement limits. Keep session history out of this file.
