# Disk Manage

Легковесное нативное приложение для macOS 14 и новее. Показывает, что занимает локальный диск, открывает найденные объекты в Finder и передаёт отчёт подключённому ИИ для рекомендаций по очистке.

Ранее приложение называлось DiskLens. Исходники и Swift-модули по-прежнему используют имя `DiskLens`, CLI называется `disklens-cli`. Bundle ID, каталог истории замеров, настройки и сервис Связки ключей сохранены для совместимости с установленной версией.

Язык продукта: английский. Интерфейс, сообщения, экспортируемые отчёты и новые рекомендации ИИ используют английский независимо от языка macOS. Ниже приведено описание действий на русском; в приложении им соответствуют английские названия. Имена пользовательских файлов и ранее сохранённые ответы ИИ не переводятся. Опубликованный архив v0.1.0 сохраняет прежний русский интерфейс.

## Работа с приложением

1. В разделе «Файлы и папки» выберите домашнюю папку, весь Mac, корень файловой системы или произвольный каталог. Содержимое открывается сразу; для ещё не измеренной области начинается сбор размеров.
2. Одинарный щелчок по имени или значку открывает любую папку. Кнопка вверх переходит к её родителю, в том числе за пределы корня замера. Навигация не ограничена глубиной отчёта. По умолчанию все файлы и папки отсортированы по размеру; доступны обратный порядок, сортировка по имени, поиск и фильтр типа. В больших папках можно перейти к следующим 500 объектам, включая мелкие файлы и пустые каталоги.
3. Во время обновления известные размеры и открытая папка остаются доступны. Полный локальный индекс обновляется по мере обхода; новые папки до измерения помечены «Уточняется». «Обновить размеры» проверяет открытую папку. В разделе «Крупные файлы» показаны до 100 самых больших файлов общего замера. «Кандидаты» содержит известные каталоги кэшей, а не команду автоматического удаления.
4. В разделе «ИИ-помощник» настройте агент, просмотрите передаваемый отчёт и запросите рекомендации. Можно также скопировать запрос или экспортировать JSON и текстовый отчёт.
5. Чтобы проверить конкретный объект, нажмите кнопку со звёздочками в его строке или «Спросить нейронку, безопасно ли это удалять» под таблицей. Без выбранной строки в обзоре проверяется открытая папка. Откроется ИИ-помощник с именем, путём и предпросмотром запроса. Если в сохранённом дереве слишком мало сведений о папке, приложение сначала уточнит её состав локальным сканированием метаданных. Это не меняет основной замер и ничего не отправляет; уточнение можно остановить. Настройте подключение при необходимости и нажмите кнопку вопроса для отправки готового запроса. Агент получает дерево выбранного объекта, дополнительный список до 240 вложенных объектов, до 40 крупных файлов и до 40 вложенных кандидатов на очистку, без остальных ветвей отчёта. Он рекомендует, что очистить и что сохранить, объясняет последствия и даёт конкретные условия для спорных материалов. Например, рабочую папку сохраняет целиком, а промежуточные рендеры рассматривает отдельно после подтверждения возможности их повторного создания. Кнопка «Весь отчёт» возвращает общий анализ.

Сканер читает только метаданные. Он не открывает содержимое файлов, не скачивает облачные файлы и не удаляет данные. При отказе в доступе показывает неполный замер. Для широкого охвата можно вручную разрешить Disk Manage полный доступ к диску в настройках конфиденциальности macOS, затем повторить сканирование.

## Один доступ к папкам

Откройте «Доступ к диску…» в боковой панели или меню Disk Manage, затем нажмите «Открыть настройки доступа». В разделе «Конфиденциальность и безопасность → Полный доступ к диску» включите Disk Manage. Если приложения нет в списке, добавьте через «+» именно запущенную копию: её путь показан в окне, кнопка «Показать приложение в Finder» выделяет нужный `.app`. После изменения доступа выполните предложенный macOS перезапуск и повторите сканирование.

Это системное разрешение охватывает в том числе защищённые данные других приложений и обычно заменяет отдельные запросы к «Загрузкам», «Документам» и «Рабочему столу». Его хранит и отзывает macOS; Disk Manage не может включить его самостоятельно. Окно не показывает неподтверждённый статус «доступ выдан». Полный доступ к диску не отменяет обычные файловые права и другие ограничения системы.

При ad-hoc подписи новая сборка может восприниматься macOS как другое приложение, даже с прежним именем и bundle ID. Поэтому разрешения могут запрашиваться снова после обновления. Для сохранения идентичности между сборками используйте один сертификат подписи и постоянное место установки. [Описание модели подписи Apple](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements).

## Удаление файлов и папок

Выберите строку и откройте меню «Удалить…» внизу окна или меню `…` нужного объекта. Доступны два действия:

- «Переместить в Корзину…», сочетание `⌘⌫`. Объект можно восстановить в Finder; место обычно освобождается после очистки Корзины. Если перенос невозможен, приложение показывает ошибку и не переходит к безвозвратному удалению.
- «Удалить безвозвратно…», сочетание `⌥⌘⌫`. Объект удаляется сразу, минуя Корзину. Отменить удаление или восстановить объект из Корзины нельзя. Это обычное файловое удаление, без гарантии физического стирания блоков или уничтожения резервных копий и снимков APFS.

Подтверждение показывает имя, полный путь и размер из замера. Папка удаляется целиком со всем содержимым. Отмена, Enter и Escape ничего не меняют. Символическая ссылка удаляется сама, без удаления её назначения. В облачных папках удаление может синхронизироваться с другими устройствами. Показанный размер не гарантирует такое же увеличение свободного места.

Удаление можно запросить и во время сканирования: приложение останавливает текущую сессию и открывает подтверждение выбранного объекта. Отмена подтверждения оставляет найденные результаты и ничего не удаляет. Во время самого удаления и открытого подтверждения другие действия заблокированы. Корень замера, домашняя папка, основные системные каталоги и Корзина защищены. После удаления рекомендации сбрасываются, изменённые пути отмечаются для проверки и автоматически начинается обновление того же корня. Известные размеры остальных объектов остаются в индексе и на экране до уточнения. Если безвозвратное удаление прервалось с ошибкой, часть содержимого уже могла исчезнуть: приложение сообщает об ошибке и повторяет замер. ИИ не запускает удаление и не выбирает объекты за пользователя.

## Кандидаты: массовое удаление и ИИ-пересмотр

В разделе «Кандидаты» меню «Удалить всех…» предлагает перенос всего списка в Корзину или отдельное безвозвратное удаление. Поиск не ограничивает это действие: подтверждение показывает количество, общий размер и каждый полный путь. Защищённые, отсутствующие и недоступные объекты перечислены отдельно с причинами пропуска; кнопка подтверждает удаление доступной части списка. Enter и Escape отменяют действие. Перед началом проверяются все доступные объекты, затем каждый повторно перед обработкой. При первой ошибке обработка останавливается. Выполненные действия не откатываются; после удаления или возможной частичной ошибки безвозвратного удаления приложение уточняет изменённые ветви, сохраняя известные данные.

Кнопка «Пересмотреть с ИИ» открывает предпросмотр запроса. После отдельной отправки агент проверяет текущих кандидатов и предлагает дополнительные объекты из общего замера. Запрос включает всех текущих кандидатов и ещё до 400 крупнейших объектов сохранённого дерева и списка файлов. Это ограниченная часть метаданных, а не полное содержимое диска. Число объектов вне запроса показано в интерфейсе. Сканирование должно завершиться или быть остановлено перед пересмотром.

ИИ предлагает оставить кандидата, убрать его из списка или добавить новый. Для каждого предложения показаны путь, размер, причина и риск. Выберите изменения и нажмите «Применить изменения». Файлы при этом остаются на месте; удаление требует отдельного подтверждения. Неизвестные ID и некорректные ответы отклоняются, пересекающиеся кандидаты не применяются. Изменения действуют в текущем замере до следующего сканирования; список не заменяется автоматически ответом ИИ.

Отдельная кнопка «Удалить рекомендованное ИИ…» доступна под предложениями и в разделе «Кандидаты». Она открывает подтверждение переноса в Корзину только объектов с явным решением ИИ «Оставить в кандидатах» и отмеченных предложений «Добавить». Неупомянутые кандидаты и предложения «Убрать из списка» не входят в это действие; поиск не ограничивает набор. Можно открыть подтверждение прямо из пересмотра или после применения изменений. В подтверждении показаны каждый путь, количество и общий размер; отмена ничего не удаляет. Обычный текстовый ответ ИИ не превращается в список удаления. После нового замера рекомендации сбрасываются.

## Постоянное дерево и обновления

Приложение хранит полное дерево измеренных файлов и папок в локальном SQLite, включая мелкие объекты, пустые каталоги и любую глубину. В памяти находится одна страница открытой папки и ограниченная сводка для экспорта. Новый запуск восстанавливает последний отчёт и индекс. После перехода со старой версии один полный замер дополняет сокращённый отчёт до полного индекса. Отдельные ветви можно открывать до окончания этого замера.

Пока приложение открыто и не занято подтверждением действий или ИИ-анализом, оно примерно каждые 5 секунд проверяет журнал FSEvents для текущей области измерения. При обнаружении изменений запускается обновление. Неизменившиеся поддеревья и отдельные файлы используются из индекса; изменённые папки перечисляются повторно, размеры предков пересчитываются. Каталог, переименованный или заменённый другим объектом, сверяется по устройству и inode. Удалённые поддеревья исключаются после успешного перечисления родителя. Изменения собственного локального хранилища не запускают повторные обновления.

Во время обновления прошлые известные размеры не обнуляются. Они отражают последний замер, пока соответствующая ветвь не проверена. Отмена сохраняет известные объекты, завершённые ветви и навигацию и приостанавливает автоматическое обновление до следующего ручного замера. Незавершённый обход не публикует доверенную позицию журнала; следующая проверка может потребовать полного обхода. Не удалось открыть папку: известные размеры остаются, ошибка показывается в интерфейсе.

Дата папки не служит доказательством неизменности вложенных файлов. Перед обходом приложение дожидается исторических событий и минимум 0,5 секунды без новых событий. FSEvents доставляется с задержкой и не даёт атомарного снимка активно изменяемого диска. Разрыв или сброс журнала и события hard links требуют полного контрольного обхода, сохраняя данные на экране. Ветви с известными hard links и пропущенными томами проверяются заново. При недоступном журнале или на сетевом томе автоматическая проверка изменений приостанавливается; «Обновить размеры» остаётся доступно и выполняет проверку метаданных. Каждый обход остаётся в пределах исходной файловой системы; открытие другого тома запускает его отдельное измерение. Права macOS по-прежнему ограничивают доступ. [Модель FSEvents](https://developer.apple.com/library/archive/documentation/Darwin/Conceptual/FSEvents_ProgGuide/UsingtheFSEventsFramework/UsingtheFSEventsFramework.html).

Для проверки без повторного использования выберите «File → Пересканировать полностью» (`⇧⌘R`) или это же действие в контекстном меню кнопки обновления.

Хранилище: `~/Library/Application Support/com.polyakovin.DiskLens/`. `file-tree.sqlite` и его WAL/SHM содержат полный индекс метаданных; `last-scan.json` хранит сводный отчёт до 32 МБ. Каталог имеет права 0700, файлы 0600. Индекс растёт с числом измеренных объектов, не ограничивает глубину и число элементов и не входит в экспорт или запросы ИИ. SQLite записывается короткими пакетами; сводный отчёт сохраняется отдельно атомарной записью. При отмене и сбое позиция журнала остаётся недоверенной. ИИ получает только зафиксированный предпросмотр ограниченной сводки после нажатия пользователя.

Для изолированной проверки сборки можно передать `--history-directory /absolute/test/path --scan /absolute/fixture/path`. Эта копия использует отдельную историю и не меняет основной индекс.

## Подключение ИИ

- **Codex CLI:** приложение ищет установленный `codex`, в том числе CLI из ChatGPT. Использует существующую авторизацию CLI, режим `read-only` и временную сессию. Настройки и hooks пользователя отключены в этом предустановленном режиме, чтобы анализ не запускал фоновые действия. При необходимости используйте отдельный режим команды для собственной конфигурации.
- **Локальная команда:** укажите абсолютный путь к исполняемому файлу и аргументы как JSON-массив строк. Запрос передаётся в stdin, ответ читается из stdout. Команда запускается напрямую, без shell. Она использует свою установленную авторизацию и свои права.
- **API:** укажите полный URL, модель и при необходимости ключ. Поддерживаются Responses и Chat Completions. HTTPS обязателен для удалённого сервера; HTTP разрешён для localhost, например локального сервера моделей. Ключ хранится в Связке ключей отдельно для каждого адреса сервера. Приложение не использует автоматически ключи из окружения или других программ.

Отчёт содержит пути, размеры и ограничения замера, без содержимого файлов. Передача начинается только по кнопке анализа. По умолчанию домашний префикс заменяется на `~`; остальные названия остаются в отчёте. Рекомендации отображаются как текст и не выполняются.

Протоколы проверены по [Responses API](https://developers.openai.com/api/reference/resources/responses), [Chat Completions](https://developers.openai.com/api/reference/resources/chat) и [документации non-interactive Codex](https://learn.chatgpt.com/docs/non-interactive-mode).

## Размеры и ограничения

Все размеры отображаются в десятичных ГБ. Сканер учитывает выделенные блоки, включая скрытые файлы и метаданные каталогов, остаётся на исходной файловой системе и не проходит по символьным ссылкам. Hard links учитываются один раз при первом обнаружении. Полный обход сохраняет все измеренные узлы в SQLite, не удерживая всё дерево в памяти. Сводный отчёт ограничен крупнейшими ветвями первых трёх уровней и 100 крупнейшими файлами; навигация читает полный индекс отдельно.

Размер папки не равен гарантированно освобождаемому месту. APFS-клоны, снимки, сжатие и защищённые каталоги могут дать расхождение с ёмкостью тома. Кандидаты не пересекаются между собой, но всё равно требуют отдельной проверки: кэш инструментов и браузеров может понадобиться скачать заново. Папки облачной синхронизации удаляются только с пониманием правил самого сервиса.

## Сборка

Требуются Xcode Command Line Tools или Xcode, Swift 5.9+.

```sh
swift test
swift build -c release
bash scripts/build-app.sh /absolute/path/to/output
```

Тест системной Корзины включается отдельно: `DISKLENS_TEST_SYSTEM_TRASH=1 swift test --filter TrashTests/testSystemTrashMovesFileFolderAndSymlinkAndAllowsRestoring`. Он перемещает и восстанавливает только созданные тестом файл, папку и символическую ссылку; нужен обычный доступ macOS к Корзине. Остальные тесты проверяют отмену, подмену пути, защищённые каталоги, ошибки и повторный замер без обращения к пользовательской Корзине.

`swift test --filter PermanentRemovalTests` проверяет безвозвратное удаление только специально созданных временных объектов, сохранность назначения символических ссылок, отказ в доступе, отмену и обновление замера после частичной ошибки.

Скрипт создаёт `Disk Manage.app` и собирает универсальную версию для Apple Silicon и Intel. По умолчанию используется локальная ad-hoc подпись с предупреждением о повторных запросах доступа после пересборки. Чтобы выбрать постоянный сертификат из Связки ключей, передайте его имя или SHA-1 в `DISKLENS_SIGNING_IDENTITY`. Ошибка подписи останавливает сборку, перехода к ad-hoc при ошибке нет.

Можно сохранить выбор один раз в локальном файле `DiskLens/.swiftpm/signing-identity` (от корня репозитория). Он исключён из Git; переменная окружения имеет приоритет. Например, из каталога `DiskLens`:

```sh
security find-identity -v -p codesigning
mkdir -p .swiftpm
printf '%s\n' 'Apple Development: имя вашего сертификата' > .swiftpm/signing-identity
bash scripts/build-app.sh /absolute/path/to/empty-output
```

Сам сертификат и его закрытый ключ должны находиться в Связке ключей. При переходе с ad-hoc на сертификат разрешение может потребоваться снова. Для публичного распространения нужны Developer ID и notarization; локальная сборка не подтверждает их наличие или сохранение системных разрешений после обновления.

CLI:

```sh
swift run disklens-cli /path/to/folder
```
