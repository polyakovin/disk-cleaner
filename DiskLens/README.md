# DiskLens

Легковесное нативное приложение для macOS 14 и новее. Показывает, что занимает локальный диск, открывает найденные объекты в Finder и передаёт отчёт подключённому ИИ для рекомендаций по очистке.

## Работа с приложением

1. Выберите домашнюю папку, весь Mac или нужный каталог, затем нажмите «Сканировать».
2. В обзоре просматривайте крупные папки. Двойной щелчок раскрывает папку, кнопка Finder показывает её на диске. На границе сохранённого дерева можно отдельно просканировать выбранную папку.
3. В разделе «Крупные файлы» показаны до 100 самых больших файлов во всём замере. «Кандидаты» содержит известные каталоги кэшей, а не команду автоматического удаления.
4. В разделе «ИИ-помощник» настройте агент, просмотрите передаваемый отчёт и запросите рекомендации. Можно также скопировать запрос или экспортировать JSON и текстовый отчёт.

Сканер читает только метаданные. Он не открывает содержимое файлов, не скачивает облачные файлы и не удаляет данные. При отказе в доступе показывает неполный замер. Для широкого охвата можно вручную разрешить DiskLens полный доступ к диску в настройках конфиденциальности macOS, затем повторить сканирование.

## Подключение ИИ

- **Codex CLI:** приложение ищет установленный `codex`, в том числе CLI из ChatGPT. Использует существующую авторизацию CLI, режим `read-only` и временную сессию. Настройки и hooks пользователя отключены в этом предустановленном режиме, чтобы анализ не запускал фоновые действия. При необходимости используйте отдельный режим команды для собственной конфигурации.
- **Локальная команда:** укажите абсолютный путь к исполняемому файлу и аргументы как JSON-массив строк. Запрос передаётся в stdin, ответ читается из stdout. Команда запускается напрямую, без shell. Она использует свою установленную авторизацию и свои права.
- **API:** укажите полный URL, модель и при необходимости ключ. Поддерживаются Responses и Chat Completions. HTTPS обязателен для удалённого сервера; HTTP разрешён для localhost, например локального сервера моделей. Ключ хранится в Связке ключей отдельно для каждого адреса сервера. Приложение не использует автоматически ключи из окружения или других программ.

Отчёт содержит пути, размеры и ограничения замера, без содержимого файлов. Передача начинается только по кнопке анализа. По умолчанию домашний префикс заменяется на `~`; остальные названия остаются в отчёте. Рекомендации отображаются как текст и не выполняются.

Протоколы проверены по [Responses API](https://developers.openai.com/api/reference/resources/responses), [Chat Completions](https://developers.openai.com/api/reference/resources/chat) и [документации non-interactive Codex](https://learn.chatgpt.com/docs/non-interactive-mode).

## Размеры и ограничения

Все размеры отображаются в десятичных ГБ. Сканер учитывает выделенные блоки, включая скрытые файлы и метаданные каталогов, остаётся на исходной файловой системе и не проходит по символьным ссылкам. Hard links учитываются один раз при первом обнаружении. Полный обход не удерживает всё дерево в памяти: сохраняются крупнейшие ветви первых трёх уровней и 100 крупнейших файлов.

Размер папки не равен гарантированно освобождаемому месту. APFS-клоны, снимки, сжатие и защищённые каталоги могут дать расхождение с ёмкостью тома. Кандидаты не пересекаются между собой, но всё равно требуют отдельной проверки: кэш инструментов и браузеров может понадобиться скачать заново. Папки облачной синхронизации удаляются только с пониманием правил самого сервиса.

## Сборка

Требуются Xcode Command Line Tools или Xcode, Swift 5.9+.

```sh
swift test
swift build -c release
bash scripts/build-app.sh /absolute/path/to/output
```

Скрипт собирает универсальную версию для Apple Silicon и Intel и подписывает её локальной ad-hoc подписью. Для публичного распространения нужно отдельно подписать приложение Developer ID и пройти notarization. Локальная сборка не претендует на такую проверку.

CLI:

```sh
swift run disklens-cli /path/to/folder
swift run disklens-cli /path/to/folder --text
```

Нет сторонних пакетов, фонового сервиса, автоматического запуска или телеметрии.
